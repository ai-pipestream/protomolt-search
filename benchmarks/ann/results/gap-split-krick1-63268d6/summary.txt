== Profiles (one CPU, taskset -c 15, --threads=1, --min-time-ms=20000, hnsw M=16 efc=200)
perf is unavailable on krick-1 (kernel.perf_event_paranoid=4 refuses even -e cpu-clock), so these come
from sampler/sampler.c: an LD_PRELOAD ITIMER_PROF sampler (~1 kHz of process CPU time, started 11 s in,
after the 8.7 s one-CPU build) whose instruction pointers sampler/symbolize.py maps through
addr2line -i. A sample goes to the first bucket that matches on its inline chain, walking outward.
This is self time only, with no call graph. Full tables: profile-*.txt. The sampler costs throughput
(qps1 under it: a 13.9k, b 2.7k, c 6.6k), so read the shares, not the rates.

(a) none k=10 ef=96 (44.9k samples): kernel 40.0% (dot_batch8 fmadd 19.2%, prefetch_range loop 9.0%),
    heap 19.6%, visited set + retain 13.6%, links 13.6% (AtomicU32 cell loads 7.1%, extend 3.0%),
    search_layer body 5.8%, rescore/results 5.2%.
(b) uncorrelated-50 k=100 ef=128 (40.2k samples): links 22.1% (AtomicU32 loads 14.8%; 917 bridges/query
    each re-copy a list), search_layer_aware body 21.4% (loop-end compares 10.3%, which mostly reflects
    mispredicts on the test/visit branches), visited set 19.8%, kernel 12.4%, mask tests 10.5%
    (Bitset::test), harness mask build 6.5% (also timed for FAISS), heap 4.8%, rescore 1.7%.
(c) near-10 k=10 ef=96 (enumerate regime: hops 0, 10,252 rows scored) (44k samples): kernel 54.5%
    (fmadd 32.2%, prefetch_range 7.4%), enumerate_skipping body (consider/bar/survives) 31.1%,
    mask iteration 7.3%, harness mask build 4.2%, heap 1.1%.

Note: unpinned turbo CI work (rustc and nextest) briefly ran on CPUs 13 and 15 at the start of
profile (b). Load was ~8 at the sweep start and ~16 later, so treat QPS as +/- a few percent.
